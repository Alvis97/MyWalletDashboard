# My Solana Dashboard

A Solana dApp for connecting wallets, viewing token balances and NFTs, built with Next.js and Solana Wallet Adapter.

## Features
- Connect Solana wallet (Phantom, Solflare etc.)
- View SOL and token balances
- View NFTs in your wallet
- Supports Mainnet and Devnet

## Tech Stack
- Next.js
- TypeScript
- Solana Wallet Adapter
- Tailwind CSS

## Getting Started

1. **Clone the repository**:
```bash
   git clone https://github.com/Alvis97/MyWalletDashboard
   cd MyWalletDashboard
```

2. **Install dependencies**:
```bash
   npm install
```

3. **Run the development server**:
```bash
   npm run dev
```
